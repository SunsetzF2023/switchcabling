① 網路環境準備

⚠️ Senior 同事指示 不能直接用 data center 的 laptop 直連 data center production 的 VPN，必須繞道 office 電腦。

連線路徑

Data Center Laptop │ └─ Remote Connect ──→ Office 電腦 │ └─ Fortinet VPN (data center production, site-to-site) │ └─ 遠端訪問 Data Center 網絡環境 │ └─ SSH 連線至 sw101 / sw306

操作步驟

1

在 Data Center 的 laptop 上，remote connect 到 Office 的電腦

2

在 Office 電腦上連接 Fortinet VPN，選擇 data center production profile（office ↔ data center site-to-site VPN）

3

VPN 連線成功後，Office 電腦即可遠端訪問 Data Center 網絡環境

打開 cmd，準備 SSH 連線至 switch

📌 備註 確認 VPN 連線穩定後再開始 switch 操作，避免操作中途斷線。

② 現場確認

1

與 Vendor 工程師一起到機櫃前，確認 sw306 及 sw101 的實體位置：

• sw101（Core Switch）— Rack G4-F07-U42

• sw306（Access Switch）— Rack G4-F09-U44

2

確認需要更換的那條網線：

• sw306 端（G4-F09-U44）：ethernet 1/1/25

• sw101 端（G4-F07-U42）：ethernet 1/1/6

3

與 Vendor 工程師確認兩端 port 的實體位置及網線走向，確保拔對線

⚠️ 注意 兩條 redundancy 線外觀可能相似，務必確認是故障的那條，不要拔錯另一條正常運作中的線。

③ Shutdown 兩端 Port（換線前）

順序：先 sw306（Access），再 sw101（Core）

B1. SSH 登入 sw306 並 shutdown port 25

# 在 cmd 中輸入 ssh jeff.fan-a@sw306.hkedcity.net # 輸入密碼登入（Dell switch 會顯示大量說明資訊） sw306# enable sw306# show running-configuration interface ethernet 1/1/25 # 預期看到： # ! # interface ethernet1/1/25 # description "sw101 1/1/6" # no shutdown # channel-group 13 mode active # no switchport # flowcontrol receive on sw306# configure terminal sw306(config)# interface ethernet 1/1/25 sw306(conf-if-eth1/1/25)# shutdown # 確認 configuration 層面已關閉 sw306(conf-if-eth1/1/25)# show running-configuration interface ethernet 1/1/25 # 確認顯示 "shutdown"（而非 "no shutdown"） sw306(conf-if-eth1/1/25)# exit sw306(config)# exit
✅ 現場確認 到機櫃前確認 sw306 port 1/1/25 的燈不亮

B2. SSH 登入 sw101 並 shutdown port 6

# 在 cmd 中輸入 ssh jeff.fan-a@sw101.hkedcity.net # 輸入密碼登入 sw101# enable sw101# show running-configuration interface ethernet 1/1/6 sw101# configure terminal sw101(config)# interface ethernet 1/1/6 sw101(conf-if-eth1/1/6)# shutdown # 確認 configuration 層面已關閉 sw101(conf-if-eth1/1/6)# show running-configuration interface ethernet 1/1/6 # 確認顯示 "shutdown"（而非 "no shutdown"） sw101(conf-if-eth1/1/6)# exit sw101(config)# exit
✅ 現場確認 到機櫃前確認 sw101 port 1/1/6 的燈不亮
⛔ 關鍵檢查點 兩個 port 的燈都確認不亮後，才通知 Vendor 工程師拔線更換！

④ 換線

1

確認兩端 port 燈都不亮後，通知 Vendor 工程師開始拔線

2

Vendor 工程師拔除舊網線，安裝新網線

• sw306 端接回 ethernet 1/1/25

• sw101 端接回 ethernet 1/1/6

3

確認新網線兩端都已插好、接頭牢固

📌 備註 此時 port 仍處於 shutdown 狀態，燈不亮是正常的。需等下一步用 cmd 啟動。

⑤ Startup 兩端 Port（換線後）

順序：先 sw101（Core），再 sw306（Access）— 與 shutdown 相反

D1. SSH 登入 sw101 並 no shutdown port 6

# 在 cmd 中輸入 ssh jeff.fan-a@sw101.hkedcity.net # 輸入密碼登入 sw101# enable sw101# configure terminal sw101(config)# interface ethernet 1/1/6 sw101(conf-if-eth1/1/6)# no shutdown # 確認 configuration 層面已啟動 sw101(conf-if-eth1/1/6)# show running-configuration interface ethernet 1/1/6 # 確認顯示 "no shutdown" sw101(conf-if-eth1/1/6)# exit sw101(config)# exit
✅ 現場確認 到機櫃前確認 sw101 port 1/1/6 的燈亮起

D2. SSH 登入 sw306 並 no shutdown port 25

# 在 cmd 中輸入 ssh jeff.fan-a@sw306.hkedcity.net # 輸入密碼登入 sw306# enable sw306# configure terminal sw306(config)# interface ethernet 1/1/25 sw306(conf-if-eth1/1/25)# no shutdown # 確認 configuration 層面已啟動 sw306(conf-if-eth1/1/25)# show running-configuration interface ethernet 1/1/25 # 確認顯示 "no shutdown" sw306(conf-if-eth1/1/25)# exit sw306(config)# exit
✅ 現場確認 到機櫃前確認 sw306 port 1/1/25 的燈亮起

D3. 確認兩端 Port 都正常著燈

⛔ 關鍵檢查點 確認 sw101 port 1/1/6 及 sw306 port 1/1/25 兩個 port 的燈都正常亮起，才進入收尾階段。

⑥ 收尾與驗證

1

確認兩個 port 都正常著燈後，聯繫 Office 同事，告知換線已成功完成

2

觀察一段時間，確認 flapping 問題是否消失

可在 switch 上查看 interface 狀態：

sw306# show interface ethernet 1/1/25 sw101# show interface ethernet 1/1/6

確認 link state 穩定為 up，不再出現 up/down 反復橫跳

3

檢查 Port Channel 13 狀態（因為該 port 屬於 channel-group 13, LACP active mode）

sw306# show interfaces port-channel 13 sw101# show interfaces port-channel 13

確認 port-channel 13 正常運作，兩條 redundancy 線都在聚合群組中

4

分析結論：

• 若 flapping 消失 → 確認該網線就是問題來源

• 若 flapping 仍存在 → 問題可能在 port 本身或其他因素，需進一步排查

5

登出 switch：

sw306# exit sw101# exit

斷開 VPN 連線，關閉 remote session

🎉 完成 工作流程全部完成，記錄本次操作結果供後續參考。
